# 🏗️ Terraform Practice

A repository for my Terraform learning, configurations, and Infrastructure as Code (IaC) experiments.

# 🚀 Quick Start

Navigate to any project directory and run the standard Terraform workflow:

```
terraform init    # initialize provider plugins
terraform plan    # preview infrastructure changes
terraform apply   # provision the infrastructure
```

# ⚠️ Important: Manage Your Costs

Deploying real resources can incur charges. Always remember to tear down your infrastructure when you are done testing!

```
terraform destroy # Destroy all provisioned resources
```
